# SFML_Lab — Моделювання фізичного процесу відскоку м'яча та керованого імпульсу (Варіант 8)

Навчальний С++-проєкт для лабораторної роботи №5 з дисципліни «Технології прикладного програмування». Реалізує інтерактивне чисельне моделювання руху тіла в полі тяжіння з пружними відскоками від поверхні та керуванням за допомогою вертикальних імпульсів.

## Стек технологій
* **Мова програмування:** C++17
* **Графічна бібліотека:** SFML 3.0+ (`Graphics`, `Window`, `System`)
* **Система збирання:** CMake (3.20+) + CMake Presets
* **Менеджер пакетів:** vcpkg (Manifest mode)

## Керування у програмі
* `Space` — надати м'ячу вертикальний імпульс угору (Варіант 8)
* `Up` / `Down` — збільшити / зменшити прискорення вільного падіння (`gravity`)
* `Right` / `Left` — збільшити / зменшити коефіцієнт відновлення при відскоку (`restitution`)
* `W` / `S` — збільшити / зменшити величину керованого імпульсу (`impulseStrength`)
* `P` — поставити моделювання на паузу / продовжити (`Pause / Resume`)
* `R` — перезапустити моделювання з початкового стану (`Reset`)
* `Ліва кнопка миші` по кольорових квадратах у верхній частині вікна — змінити колір м'яча (`Red`, `Green`, `Blue`, `White`)
